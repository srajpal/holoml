# Security

Please report security problems in HoloML (for example in its parser)
privately, through GitHub's private vulnerability reporting: on this
repository's page, open **Security**, then **Report a vulnerability**. Do
not open a public issue for them.

Problems in the HyperSpace 3D browser belong in its own repository:
https://github.com/srajpal/hypersol-hyperspace-3d/security

This is a personal project maintained in spare time; please allow a few
days for an answer. Only the latest code on `main` is supported.
