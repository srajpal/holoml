# Branding

social-preview.png is the picture GitHub and link cards show for this
repository (1280 by 640): the name and a line of words over four of
the examples' pictures from site/pictures. It is drawn by the browser
repository's script, `pnpm --filter @hypersol/browser social-previews`
there (apps/browser/scripts/social-previews.mjs in
https://github.com/srajpal/hypersol-hyperspace-3d), which writes it
here when the two repositories are side by side; run it again when the
words or the examples' pictures change. Uploaded by hand in Settings,
General, Social preview (the browser's issue #95).
